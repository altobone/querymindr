About

What is Querymindr?

Querymindr is a local search tool built for large external drives. It indexes your files into a fast local database, then lets you search by keyword, partial title, or fuzzy spelling in seconds. It also scans for duplicate files so you can reclaim wasted space without guessing.

Everything runs entirely on your Mac. Your files never leave your computer — there is no cloud service and no account required. Optional AI features use the Anthropic API and require your own API key.

Querymindr is free to use. There is no subscription and no license key.

Getting Started

Install and Start Searching

1

Install Querymindr

Run the Querymindr .pkg installer and follow the installation prompts. No Node.js or Terminal setup is required. Querymindr runs in the background and starts automatically when you log in.

2

Open Querymindr

Querymindr opens automatically in your browser after installation. You can also open http://localhost:8080/querymindr/ in your browser. The application is accessible only from your own Mac.

3

Add your drives or folders

Go to Settings → Index Engine. Add one or more drives or folders that you want Querymindr to search. Your external drives must be connected and mounted before indexing.

4

Build your index

Click Quick Update to begin building the search index. The process runs in the background. A progress bar shows the current status. The index must complete at least once before search and duplicate detection are available.

Indexing

Keeping Your Index Current

Quick Update

Scans folders that have changed recently and is the normal way to keep your index current after adding or changing files.

Full Re-index

Scans every file from scratch. This can take several hours on large drives and is intended for major reorganizations or situations where you need to rebuild the index.

Automatic updates

In Settings, you can schedule automatic indexing every hour, every 12 hours, every 24 hours, or disable automatic updates and run indexing manually.

Search

Finding Files and Duplicates

Search your indexed files by keyword, partial title, or fuzzy spelling. Querymindr searches the local index rather than scanning the drive from scratch for every query.

Querymindr can also identify duplicate files by calculating file fingerprints. In Settings, the Checksum File Size Limit controls which files are fingerprinted. A higher limit can identify duplicates among larger files but increases indexing time.

Optional AI

AI-Powered Search

Querymindr can use Claude through the Anthropic API for natural-language search, summaries, and smart file discovery. AI is optional — keyword search works without an API key.

To enable AI, open Settings, enter your Anthropic API key, and choose an AI model. Claude Haiku is faster and less expensive; Claude Sonnet is more powerful for complex or vague queries.

Privacy

Your Files Stay on Your Mac

Local by design

Querymindr's file index runs on your Mac, and the application is served through localhost. Your files are not uploaded to a Querymindr cloud service. If you enable AI features, the information sent to Anthropic is governed by your use of the Anthropic API.
