About

What is Querymindr?

Querymindr is a local search tool built for large external drives. It indexes every file on your drive into a fast local database, then lets you search by keyword, partial title, or fuzzy spelling in seconds — no matter how many terabytes you have. It also scans for duplicate files so you can reclaim wasted space without guessing.

Everything runs entirely on your own machine. Your files never leave your computer — no cloud, no account required. Add an optional Anthropic API key to unlock AI-powered natural language search, instant summaries, and smart file discovery.

Querymindr is a one-time purchase of $29 — no subscription, yours forever.

Windows SmartScreen warning on first launch

Because Querymindr is a new application without millions of downloads, Windows Defender SmartScreen may display a blue "Windows protected your PC" dialog when you run the installer. This is normal for any recently released Windows app — it does not mean the file is unsafe.

To proceed: click "More info" in the dialog, then click "Run anyway". The warning disappears permanently after enough users install the app and Windows builds trust in the file's signature.
