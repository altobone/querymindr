Installation &
Setup Guide

// mac · linux · natural language file search

Prerequisites
Before You Start
Mac & Linux
1
Download and install Node.js from nodejs.org — choose the LTS version.
2
Open Terminal and install pnpm:
npm install -g pnpm
3
Connect and mount your external drive before running the installer.
Installation
Platform Setup
macOS
1
Optional: Install Xcode command-line tools for the menu bar icon:
xcode-select --install
Skip if Xcode is already installed.
2
Place querymindr-release.tar.gz in your Downloads folder.
3
Run in Terminal:
cd ~/Downloads && tar -xzf querymindr-release.tar.gz && cd querymindr-release && bash install-querymindr.sh
⌘ After install, Querymindr opens in your browser automatically and starts at every login. A magnifying glass icon appears in your menu bar.
Linux
1
Place querymindr-release.tar.gz in your home folder.
2
Run in Terminal — replace the path with your actual drive location:
cd ~ && tar -xzf querymindr-release.tar.gz && cd querymindr-release && ROOT_DIR=/media/yourname/drivename bash install-querymindr-linux.sh
ℹ Runs as a background service that starts automatically at login.

Useful commands

systemctl --user status file-finderCheck if running
systemctl --user stop file-finderStop the service
systemctl --user start file-finderStart it again
journalctl --user -u file-finder -fView live logs
Access
Opening Querymindr

Once installed, open your browser and navigate to:

URL http://localhost:8080/file-finder/
★ Bookmark this page. Querymindr only works on your own computer — it is not accessible from the internet.
Configuration
First-Time Setup

Click Settings in the left sidebar to configure each option below.

1
Claude API Key
▶
Querymindr uses Claude AI for natural language search. Get your key from console.anthropic.com — sign up, create a key, paste it into the Claude API Key field, then click Save Key.
↳ Without a key, keyword search still works. Only AI-powered search requires it.
2
AI Model
▶
  • Claude Haiku — faster and cheaper; great for most searches
  • Claude Sonnet — more powerful; better for complex or vague queries
3
Auto-Update Schedule
▶
Controls how often Querymindr automatically scans for new or changed files.
  • Disabled — never runs automatically; use the buttons manually
  • Every hour — keeps the index very current
  • Every 12 hours — default (runs at midnight and noon)
  • Every 24 hours — once a day
4
Checksum File Size Limit
▶
Controls which files get fingerprinted for duplicate detection. Larger limits catch more duplicates but increase index time.
  • 100 MB — default; covers most audio tracks
  • 250 MB — covers stems and rendered mixes
  • 500 MB — covers most video exports
5
Index Engine
▶
Point Querymindr to your drives to build the searchable database.
  • Root Directories — add one or more drive paths. Click + or press Enter to add, X to remove. Multiple drives supported.
  • Quick Update — scans only recently changed folders. Finishes in minutes. Use regularly.
  • Full Re-index — scans every file from scratch. Takes several hours. Use only after a major drive reorganisation.
↳ The index must complete at least once before search and duplicate detection are available. A progress bar shows percentage complete.
