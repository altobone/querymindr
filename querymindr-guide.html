Querymindr

Installation &
User Guide

Querymindr is a local search tool for large external drives. It indexes every file on your drive — names, folders, sizes, and types — into a fast database that lives on your Mac. You search it through a browser window: type a word, a partial title, or a rough description, and Querymindr finds the matching files in seconds, no matter how many terabytes you have. Because everything runs on your own machine, your files never leave your computer.

Installation
Getting Started
macOS
1
After installation, Querymindr opens automatically in your browser.
2
Open Settings → Index Engine and add the external drive or folders you want Querymindr to index.
3
Run Quick Update to build or update the search index.
4
Go to Search and start searching your files.
⌘ Querymindr runs locally on your Mac. Your files remain on your computer.
Access
Opening Querymindr

Once installed, open your browser and navigate to:

URL http://localhost:8080/querymindr/
★ Bookmark this page. Querymindr only works on your own computer — it is not accessible from the internet.
Configuration
First-Time Setup

Click Settings in the left sidebar to configure each option below.

1
Index Engine
▶
Point Querymindr to your drives to build the searchable database.
  • Root Directories — add one or more drive paths. Click + or press Enter to add, X to remove. Multiple drives supported.
  • Quick Update — scans only recently changed folders. Finishes in minutes. Use this regularly to keep the index current.
  • Full Re-index — scans every file from scratch. Takes several hours on large drives. Use only after a major drive reorganisation.
↳ The index must complete at least once before search is available. A progress bar shows percentage complete.
2
Auto-Update Schedule
▶
Controls how often Querymindr automatically scans for new or changed files.
  • Disabled — never runs automatically; use the buttons manually
  • Every hour — keeps the index very current
  • Every 12 hours — default (runs at midnight and noon)
  • Every 24 hours — once a day
3
Checksum File Size Limit
▶
Controls which files get fingerprinted for duplicate detection. Larger limits catch more duplicates but increase index time.
  • 100 MB — default; covers most audio tracks
  • 250 MB — covers stems and rendered mixes
  • 500 MB — covers most video exports
4
Claude API Key — optional, unlocks AI features
▶
Adding a Claude API key unlocks AI Magic Search and AI File Summaries. Both features are completely hidden in the app until a key is saved — you won't see any error messages or broken buttons without one.

To get a key: go to console.anthropic.com, sign up, create a key, paste it into the Claude API Key field, and click Save Key. The AI features will appear immediately.
↳ Querymindr is fully usable without a key. Keyword search, fuzzy matching, folder browsing, and Find More Like This all work with no API required.
5
AI Model — only shown with API key
▶
  • Claude Haiku — faster and cheaper; great for most searches
  • Claude Sonnet — more powerful; better for complex or vague queries
Using the App
How to Search

Type in the search bar at the top of the page. Results appear as you type. Use the tabs and filters on the left to narrow results by file type, size, or date.

Standard
Keyword Search
The default mode. Type any word or combination of words and Querymindr searches file names across your entire indexed drive. Every word you type must appear in the file name — searching jazz piano 2022 finds files that contain all three words somewhere in their name or path.
  • Works on partial words — trom finds trombone, Trombones_mix.wav, etc.
  • Not case sensitive
  • If nothing matches exactly, Querymindr automatically tries fuzzy matching (see below)
Auto
Fuzzy / Typo Tolerance
You don't need to do anything to enable this — it kicks in automatically when a keyword search returns zero results. If your query is at least five characters, Querymindr will look for close matches and suggest what you might have meant.
  • trambones → finds trombones
  • violen → finds violin, violins
  • Shorter queries (under 5 characters) don't use fuzzy matching, to avoid unrelated results
↳ Fuzzy matching runs entirely on your Mac — no internet or API key required.
AI
AI Magic Search
When a Claude API key is configured, a toggle appears in the search bar to switch between Standard and AI Magic mode. In AI Magic mode, describe what you're looking for in everyday language and Claude will interpret it into a targeted search.
  • "80s synth demos recorded in the studio" → searches for relevant terms and patterns
  • "choir sessions from the Hamilton project" → breaks out key words and folder names
  • Good for searches where you remember the vibe but not the exact file name
↳ AI Magic Search sends your query text to Anthropic's servers to generate search terms. File names and paths from results are processed locally.
Using the App
Folder Search & Browse

Switch to the Folders tab to search by folder name instead of file name.

1
Click the Folders tab and type a folder name. Results show only folders whose name contains your search words — not subfolders with unrelated names.
2
Click any folder row to browse its contents. A breadcrumb trail at the top lets you navigate back. Your original search is saved so you return to it when you exit.
3
Click Reveal in Finder on any folder or file to jump directly to that item in macOS Finder — no copying paths or manual navigation required.
Using the App
File Detail Panel

Click any file in the results list to open a detail panel on the right with more information and actions.

→
File info — name, full path, size, type, and date last modified.
→
Reveal in Finder — opens the file's location in macOS Finder immediately.
→
Find More Like This — triggers a new search for files with similar names or from the same folder. Good for finding related takes, alternate versions, or project files.
→
AI File Summary requires API key — generates a short description of what the file likely contains based on its name, location, and type. The summary is saved so it only needs to be generated once per file.
