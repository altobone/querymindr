QUERYMINDR — USER GUIDE
=======================

What is Querymindr?

Querymindr is a local file-search tool designed for large external drives and folders. It indexes your files locally on your Mac so you can quickly search for files and identify duplicates.

Querymindr is free to use. There is no subscription and no license key.

COMPATIBILITY
-------------

Querymindr currently runs on macOS.

Your files and search index remain on your Mac. Querymindr does not require a cloud account or remote search service.

INSTALLATION
------------

Install Querymindr using the provided Mac installer package (.pkg).

The installer sets up the Querymindr background service and starts it automatically when you log in.

You do not need to install Node.js or use Terminal to run Querymindr.

After installation, Querymindr opens automatically in your web browser at:

http://localhost:8080/querymindr/

The Querymindr menu-bar application is optional. If it is not installed automatically, Xcode Command Line Tools may be required to build it.

FIRST SETUP
-----------

1. Open Querymindr.

2. Go to Settings → Index Engine.

3. Add the drives or folders you want Querymindr to search.

   External drives must be connected and mounted before they can be indexed.

4. Click Quick Update.

Querymindr will index the selected locations in the background. You can continue using your Mac while indexing is in progress.

The initial index may take some time, particularly for a large external drive.

SEARCHING
---------

Once indexing is complete, use the main search page to find files.

Search supports normal keyword and fuzzy matching, making it useful even when you do not remember the exact filename.

DUPLICATE DETECTION
-------------------

Querymindr can identify duplicate files within the indexed locations.

For reliable duplicate results, allow the initial indexing operation to finish before relying on duplicate detection.

INDEX UPDATES
-------------

Quick Update checks the indexed locations for changes and updates the index without rebuilding everything from scratch.

Use Quick Update periodically to keep the index current.

FULL RE-INDEX
-------------

Use Full Re-index when you want to rebuild the index from scratch.

This can be useful after major changes to the indexed folders or if you believe the index no longer accurately reflects the files on your drives.

AUTOMATIC UPDATES
-----------------

Querymindr can update the index automatically according to its configured schedule.

You can manage indexing behavior from Settings → Index Engine.

OPTIONAL AI FEATURES
--------------------

Querymindr's core file search works without AI.

Optional AI features can use the Anthropic API to provide additional file summaries and related functionality.

If you enable AI features, Querymindr sends the information required for those AI requests to Anthropic. Your use of the Anthropic API is subject to Anthropic's policies and terms.

PRIVACY
-------

Querymindr is designed around local file search.

Your files are indexed locally on your Mac. The Querymindr interface is served locally and is accessed through localhost.

Querymindr does not require you to upload your files to a Querymindr cloud service.

If you enable optional AI features, information associated with those requests is sent to Anthropic as described above.

TROUBLESHOOTING
---------------

Querymindr does not find my files
    Open Settings → Index Engine and confirm that the correct drive or folders have been added. Make sure external drives are connected and mounted.

Search returns no results
    Confirm that indexing has completed. If necessary, run Quick Update.

The index seems incorrect
    Try Quick Update first. If the problem persists, use Full Re-index.

Querymindr does not open
    Make sure the Querymindr background service is running and try opening:

    http://localhost:8080/querymindr/

If you still have a problem, check the Querymindr installation and service status.
